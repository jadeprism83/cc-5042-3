# 距离场字形图集：误差与尺寸报告

本报告由 `tools/compare-report.mjs` 生成。它将图集的 R8 距离场按着色器相同的解码与
覆盖函数（`shared/sdf.mjs` 的 `decodeDistance` / `coverageFromPixels`）重建，
与**精确非零环绕轮廓光栅化**（`shared/raster.mjs`，每像素 8 条子扫描线）逐像素比较。
两条路径的算法不同，因此一致性是证据而非同义反复。

坐标：SDF 侧与片元着色器一致，每像素中心采样一次（不做超采样），
因此报告的是观者真正看到的误差；轮廓侧每像素 8 条子扫描线，横向精确覆盖。
两者都在同一位图网格上、以字形原点为基准对齐。

指标：MAE（全图平均绝对覆盖误差）、RMSE、MaxErr、IoU（α≥0.5 的并交比）、
EdgeMAE（只统计轮廓附近 2%<α<98% 的像素，反映边缘质量）。

## 支持边界

- 最小测试字号 12 px 时，图集为 64 texel/em，
  每屏幕像素约对应 5.3 个图集 texel，距离场仍有冗余；
  最差 EdgeMAE 为 0.1496（sans-thin U+3A）。
- 放大到 192 px 时，每个图集 texel 被拉伸到 3.00 屏幕像素，
  双线性插值使边缘出现 3.00 px 量级的线性过渡，平均 EdgeMAE 0.0661。
  这是距离场采样的固有带宽限制：场值仍正确，但梯度被插值平滑，尖角会轻微圆化。
  因此“边缘一致”仅指**每个尺寸使用同一 1 px 屏幕空间阈值与同一覆盖公式**，
  不声称任意放大倍率下与轮廓光栅化逐像素相同；上面的数字给出实际偏差。
- 细字（ExtraLight）平均 IoU 0.870，粗字（Bold）平均 IoU 0.983。
  细笔画的相对误差更高，这是距离场在细笔画两侧只有少量 texel 采样导致的；
  提高 `--texels-per-em` 可缩小该误差，代价是图集线性增大。
